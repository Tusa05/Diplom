# Дипломный проект: Автоматизация тестирования на примере сервиса «Кинопоиск»

## Описание проекта

Данный проект представляет собой фреймворк для автоматизации тестирования ключевых функций веб-приложения «Кинопоиск». Тестирование включает в себя UI- (User Interface) и API- (Application Programming Interface) тесты, разработанные с использованием Python.
**Цель:** Разработать фреймворк для автоматизированного тестирования, покрывающий ключевой функционал приложения, демонстрируя навыки работы с современными инструментами автоматизации.

## Используемый стек технологий

**Язык программирования:** Python
**Фреймворк для тестов:** pytest
**UI-тестирование:** Selenium WebDriver
**API-тестирование:** requests
**Система отчетов:** Allure Reports

## Структура проекта

Проект имеет следующую, простую и понятную структуру:
kinopoisk-autotests-diplom/
|--.gitignore # Список файлов, которые игнорируются Git
|-- pytest.ini # Конфигурация pytest

## Настройка и запуск проекта

1. Установка зависимостей
   Чтобы установить все необходимые библиотеки, используйте команду:
   bash
   pip install -r requirements.txt

2. Конфигурация проекта
   Перед запуском тестов необходимо заполнить файл config.py вашими данными.

### **ВАЖНО:**

После заполнения этого файла не забудьте удалить конфиденциальные данные (логин/пароль) перед отправкой репозитория в публичный доступ!
_BASE_URL:_ Адрес веб-сайта, который вы тестируете.
_API_BASE_URL:_ Адрес API. Токен для API был получен через Telegram-бота @kinopoiskdev_bot.
_USER_EMAIL, USER_PASSWORD:_ Данные для авторизации, которые будут использоваться в тесте.
_AUTH_TOKEN:_ Ваш токен для доступа к API. 3. Запуск автотестов
Проект поддерживает три режима запуска, используя метки (-m):
Запуск всех тестов:
bash
pytest

Запуск только UI-тестов:
bash
pytest -m ui

Запуск только API-тестов:
bash
pytest -m api

4. Генерация отчета Allure
   Для создания подробного отчета о выполнении тестов выполните следующие шаги:
   Запустите тесты с параметром --alluredir, чтобы сохранить результаты:
   bash
   pytest --alluredir=./allure-results

Сгенерируйте и просмотрите отчет в вашем браузере:
bash
allure serve ./allure-results

Важно: Для allure serve у вас должен быть установлен Allure Commandline.

## Найденные дефекты

В процессе автоматизированного тестирования были обнаружены следующие дефекты в работе приложения:

1. Некорректный статус-код API для несуществующих эндпоинтов.
   Описание: API возвращает статус 200 OK при обращении к несуществующему пути (/some/nonexistent/path), хотя должен возвращать 404 Not Found. Этот дефект был найден тестом test_non_existent_endpoint.
2. Нестабильность при одновременном запуске UI- и API-тестов.
   Описание: При запуске всех тестов вместе (pytest), UI-тесты, использующие Selenium, мешают API-тестам, вызывая ошибки TimeoutException. Для обеспечения стабильности тесты необходимо запускать отдельно (pytest -m ui и pytest -m api). Дефект тестового окружения, выявленный в процессе выполнения автотестов.
